# Code Lab Challenge 0 - Lost & Found Linear Search

In this challenge you will design and implement a linear search function, use it to find items in a list, and measure how much work the algorithm does in different situations (item at the front, in the middle, at the end, or missing entirely). You will compare your observations to Python's built-in `in` operator and reflect on when linear search is "good enough."

You will also practice using the PyCharm debugger to step through the algorithm and watch how variables change over time.

*Note: Students with deeper programming experience can try the extra stretch challenges in Phase 4*


### Program Requirements

0.  Write a function `linear_search(items, key)` that:
    * Takes a list of strings `items` and a search target string `key`.
    -   Example:
    -   ```python
        items = ["pencil", "phone", "mouse"]
        linear_search(items, "phone")
        ```
    * Scans the list from index 0 upward, comparing each element to `key`.
        -   Use a loop of this form: `for index in range(len(items))`
    * Counts how many comparisons it performs.
        -   A comparison is any use of the operators `==`, `!=`, `<`, `<=`, etc.
    * Returns the index where `key` is found, or `-1` if it is not in the list.
    * Prints the total number of comparisons before returning.
0.  In `main()`, create a list of at least 7 desk items (e.g. `"pencil"`, `"phone"`, `"mouse"`).
0.  Prompt the user for an item to search for and call `linear_search(items, key)`.
0.  Print a clear result message:
    * If the index is `-1`, say that the item was not found.
    * Otherwise, report the index where it was found.
0.  Run and record four specific test cases on the same list:

    * A key that appears in the **middle** of the list.
    * A key that appears at the **end** of the list.
    * A key that does **not** appear in the list.
    For each test, note the number of comparisons your function reports.
0.  After your tests, use Python's `in` operator (for example, `print(key in items)`) and briefly comment on Wooclap how the information from `linear_search` differs from the information given by `key in items`.
